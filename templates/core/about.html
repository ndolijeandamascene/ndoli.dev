Professional Identity

I am NDOLI Jean Damascene, an IT professional, software developer, and systems builder based in Rwanda. My work is driven by a straightforward philosophy: technology is only as valuable as the real-world problems it solves and the reliability with which it performs.

Rather than merely assembling off-the-shelf templates or reciting buzzwords, I focus on the end-to-end craft of software engineering: designing normalized relational schemas, implementing secure RESTful APIs, orchestrating AI/RAG retrieval pipelines, and configuring hardened production server environments.

Core Engineering Philosophy

"Simplicity is prerequisite for reliability. Build software with clear data boundaries, verify every assumption with tests, and prioritize evidence of work over claims of expertise."

My architectural approach follows these foundational tenets:

  • Security & Data Governance: Zero trust on user inputs, robust CSRF/CORS barriers, strict password hashing, and isolation of sensitive credentials.
  • Maintainability First: Clean Django architecture, explicit service layers, and modular separation rather than bloated monolithic spaghetti.
  • Evidence over Hype: When integrating AI, grounding responses in verified knowledge graphs and local vector databases (e.g., PostgreSQL with pgvector) rather than blind unconstrained generation.
  • Performance by Design: Server-side rendering, efficient SQL joins (`select_related`/`prefetch_related`), minimal frontend runtime baggage, and fast responsive delivery.
